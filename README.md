# Medical & Healthcare Website

A complete medical and healthcare website built with Next.js, featuring doctor appointments, medicine ordering, medical reports, and admin panel.

## Features

- 🏥 Professional homepage with hero banner and search functionality
- 👨‍⚕️ Doctor profiles with filters and booking system
- 💊 Medicine ordering system with cart
- 📋 Appointment booking with confirmation
- 📄 Medical reports upload and viewing
- 👤 User authentication and dashboard
- 🔐 Admin panel for managing doctors, appointments, medicines, and users

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser
